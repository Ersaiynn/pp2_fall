# Practice 6

File handling, directory management and built-in functions in Python.

- file_handling - write, read, append, copy and delete files
- directory_management - create, list, find and move files and folders
- builtin_functions - map, filter, reduce, enumerate, zip, type conversions
- dir_file_exercises - 8 exercises with paths and files

Run each script from its own folder:

```
python write_files.py
```
